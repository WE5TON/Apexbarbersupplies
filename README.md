# Apex Barber Supplies

Website for a UK-based barbering supplier, featuring the current APEX PRO clipper and trimmer range.

## Local preview

Run `python3 -m http.server 8000` from this directory, then open http://localhost:8000. No installation or build step is needed.

## Features

- Responsive product collection with orange and blue colour selection
- Automatic colour crossfades, motion pause and reduced-motion support
- Individual product popups and a side-by-side comparison
- Full-screen navigation and product care information
- Amazon launch messaging and an Instagram placeholder

## Links

Amazon is currently marked as coming soon. Verified Amazon and Instagram links can be added to the `destinations` object in `js/app.js` when ready. Update the launch wording when shopping becomes available.

## Assets and specifications

Website assets are included locally. Product scenes use AI-generated imagery based on supplied product and packaging references. Product specifications come from the supplied packaging; runtime varies with use.

This repository contains the website only. Source packaging files, design mockups and previous design archives are kept outside the uploaded site.
